# Flyza Tours & Travels ✈️
> **Beyond Every Journey**

Flyza Tours & Travels is a modern, responsive travel agency website frontend built using **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

* **Home Page (`/`)**: Hero destination search, counter statistics, featured destinations, popular tour packages, Why Choose Us pillars, traveler testimonials, and interactive Call to Action.
* **Tour Packages (`/tours`)**: Dynamic search, category filters (Luxury, Adventure, Romantic, Culture, Wellness), price/rating sorting, and package details.
* **Single Tour Detail (`/tours/[id]`)**: Comprehensive day-by-day itineraries, highlights, inclusions/exclusions, and instant WhatsApp booking.
* **Our Trusted Channel Partner (`/channel-partner` & `/medical-tourism`)**:
  * Strategic partnership with **My 1 Health**.
  * Complete hospital directories across **20 countries** (India, USA, Singapore, Thailand, South Korea, Malaysia, UAE, Turkey, UK, Germany, Spain, Egypt, Kenya, Saudi Arabia, etc.).
  * Interactive appointment booking modal that automatically formats and sends patient inquiries to WhatsApp.
* **Destinations (`/destinations`)**: Multi-continent showcase with regional destination cards.
* **About Us (`/about`)**: Company vision, core values, milestone timeline, and leadership.
* **Contact Us (`/contact`)**: Consultation & inquiry form with auto-redirect to WhatsApp, quick contact cards, operating hours, FAQs, and embedded Google Map for GEC Chattogram.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AbuTawhidRian/Flyza_travel.git
   cd Flyza_travel
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
